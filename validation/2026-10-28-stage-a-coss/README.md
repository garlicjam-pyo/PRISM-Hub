# Stage A 출력용량 손실 재평가(E31·TB25) 근거 (2026-10-28)

Stage A 손실 모델의 출력용량 항(4·E\_oss·f\_s, E\_oss 24 µJ)을 실제 소자 데이터와 영전류 스위칭의 하드 스위칭 전이 손실(Q\_oss·V)로 고치고, 그 영향과 설계 수정안을 계산한 근거 파일이다. 문서는 [docs/37](../../docs/37_StageA_출력용량손실_재평가_E31_TB25.md)이다.

- **검증 코드**: `submission/verification_code`의 `E31_stage_a_coss.py`다. 소자 데이터는 `submission/verification_code/data/datasheets/*.json`(데이터시트 표 값과 출처)이다. 아래 E31 파일은 실행 결과(`results/E31`)를 옮긴 것이다.
- **회로 모델**: [TB25](../../simulink/tb/TB25_StageA_Coss/README.md)(Stage A 1위상 + 스위치 출력용량)다.
