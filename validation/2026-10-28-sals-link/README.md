# 보호 상태기계와 SALS의 연동(E29·TB23) 근거 (2026-10-28)

R2 창 조정 모듈의 고장 강등 순서에 400 V 부하 분리·감발 명령의 전달(접촉기, SALS 메시지 지연·손실·워치독)과 부하 등급별 계약 응답을 넣어 확인한 근거 파일이다. 이중 고장의 Stage A 협조 정지도 함께 확인했다. 문서는 [docs/35](../../docs/35_보호상태기계_SALS_연동_E29_TB23.md)다.

- **검증 코드**: `submission/verification_code`의 `E29_sals_degradation.py`와 공용 모듈 `sals_loads.py`다. `E17_protection_integration.py`의 `r2_run`에 선택 인자 `p_c`·`sals`·`event2`·`astop`·`fs_brake`를 더했다. 주지 않으면 이전과 같다. 아래 E29 파일은 실행 결과(`results/E29`)를 옮긴 것이다.
- **회로 모델**: [TB23](../../simulink/tb/TB23_R2_SALS_Link/README.md)이다. TB13 회로에 등급별 계약 응답 부하, SALS 모드 상태기계, Stage A 정지 스위치 + C\_A를 더했다.
