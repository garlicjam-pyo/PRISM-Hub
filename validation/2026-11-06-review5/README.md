# 제출 전 두 번째 통합 검토 대응(E46) 근거

판정 기준과 코드는 실행 전에 커밋했다(19e4e6b). nc·fig는 실행 전 추가 등록(de4a064·d67b7cc), vmap2 (c)의 점 집합 정정(de4a064)은 1차 실행(141점) 뒤의 정정이다(판정 기준 같음). h1s·stat은 독립 확인 뒤 실행 전에 추가 등록했다(8fd5ebd). 실행 경과의 코드 수정은 118d6cd다. 정리 문서는 docs/51이다. 검토 기준 커밋은 36a7833이다.

실행 경과: 저장 자료 재집계 부분(power, h1, h2s, h4, tb25, e31, tb15, prot, loss, gate, cache)은 코드 디버깅을 위해 등록 전에 시험 실행했다(새 물리 계산 아님, 기준 변경 없음). 새 계산 부분은 등록 뒤 실행 결과만 쓴다. fig의 1차 실행은 사양 팩에서 멈춰 숫자 팩만 그리도록 고쳤다. 그 사이 nc·ldab·fig의 중간 실행 화면 출력은 파일로 남기지 않았다. 3장 원고의 78.74 A는 ramp 실행 완료 전에 검토자 수치로 먼저 들어갔고, 이후 E46 ramp가 같은 값을 냈다.
