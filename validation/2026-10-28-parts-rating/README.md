# 부품 정격 표(E34) 근거 (2026-10-28)

모의에서 나온 부품 스트레스를 후보 부품의 데이터시트 정격과 대조한 근거 파일이다. Stage A는 25 kHz 설계(A25) 기준이다. 문서는 [docs/39](../../docs/39_부품정격표_E34.md)이다.

- **검증 코드**: `submission/verification_code`의 `E34_parts_rating.py`다. 후보 부품의 데이터시트 표 값과 출처(URL, 열람일, 추출 방법)는 `submission/verification_code/data/datasheets/*.json`이다.
- **입력**: E26(클램프 사건, 재계산), E29(바이패스·제동·H-브리지 사례 재실행, 접촉기 저장값), E32·E33(Stage A).

| 파일 | 내용 |
|---|---|
| E34/clamp.json | V\_A 클램프 사건 32개: 저항 에너지·첨두, 켬·끔 횟수, IGBT 에너지·온도(P4·P5) |
| E34/prot.json | 바이패스 소프트 투입·H-브리지 역방향 도통의 Z\_th 온도, 제동 에너지, 접촉기(P6–P9), EPC2305 Foster 맞춤 |
| E34/stagea.json | Stage A 정격점 모의(위상별 실효·첨두·v\_C·위치 손실), P1–P3 |
| E34/stagea\_run1\_E33key.json | 1차 실행(E33 결과 열쇠 오류로 과도·고장 첨두가 빠짐, 보관) |
| E34/table.json, table.csv | 부품 정격 표 |
| E34/E34\_run.log, E34\_parts\_rating.png | 실행 기록, 그림 |
