# 외부 검토 대응과 남은 설계 과제(E38) 근거 (2026-10-29)

외부 검토(2026-10-29)의 지적 6곳과 남은 설계 과제 두 가지(P6 바이패스 소프트 투입, F2 이중 고장 경로전류)를 설계 변경과 재계산으로 다시 판정한 근거 파일이다. 문서는 docs/43이다.

- **검증 코드**: `submission/verification_code/python/E38_review_response.py`(판정 기준은 실행 전에 커밋).
- **공용 모듈의 선택 인자(기본값이면 이전과 같음, 회귀 확인 차 0)**:
  - `E26_charging_stop`: 클램프 가지 수 `n`, 스위치 강하 `vdrop`.
  - `sals_loads.SalsLoads`: Stage C 일시 정지·재개(`sc_pause`·`sc_resume`), 400 V 부하 정지(`load_stop`).
  - `E17_protection_integration.r2_run`: `sc_pause`(링크 붕괴 시작 때 Stage C 일시 정지, 강등 0.5 ms 뒤 재개), `load_stop`(이중 고장 진입 때 400 V 부하 전체를 램프로 정지).
- **회로 모델**: TB30(클램프 재선정), TB31(Stage C 일시 정지·부하 정지) — 기준은 각 README에 실행 전에 적는다.
