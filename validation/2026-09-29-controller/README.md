# 제어기 재설계 R1 검증 근거 (2026-09-29)

[docs/15](../../docs/15_제어기_재설계_R1.md)와 중간보고서 v1.2 6.9–6.10절의 근거 파일이다. 평균모델과 판정 함수는 `final-report` 브랜치의 유한 링크 6상태 평균모델과 같다. **Python 단독 계산이며, MATLAB 교차검증은 예정이다.**

| 파일 | 내용 | 생성 |
|---|---|---|
| linear.json | 표본화 선형화 추가 지연 여유와 스펙트럼 반경. 기존·R1 × 6개 전압 × 4개 부하 | `python python/ctrl_validate.py linear` |
| grid.json | Tier-1·Tier-2 격자 552건. req_dynamic.py와 같은 조건과 판정 | `... grid` |
| delay.json | Tier-1 대표 3 스텝의 추가 지연 경계. 640·920 V, +3.0–5.0 µs, 적분 0.1 µs | `... delay` |
| corners.json | 복합 ±10 % 공차 128개 코너(640 V). Tier-1 15→25 kW(+3.0 µs), Tier-2 1→25 kW | `... corners` |
| corners_lh5.json | Tier-2 실패 코너 26개를 L_h ±5 %로 재시험 | `... corners_lh5` |
| sequences.json | 계약 최악 시퀀스 48건(공칭·L_h −10 %·L +10 %·지연 +3.0 µs) | `... sequences` |
| exploration.json | 기각한 대안(대역폭 저하, 전압항 포화)과 지연 한계 모드의 구성 | `python python/ctrl_explore.py` |

판정은 docs/14의 Tier 기준에 내부 진동 검사를 더한 것이다. 마지막 1 ms의 i_h 변동폭 ≤ 1 A, 변조율 변동폭 ≤ 0.01을 요구한다. 선형화 지연 여유는 0.1 µs 간격 상향 탐색으로 구한다. 안정성이 지연에 대해 단조가 아니기 때문이다.

`pprc_two_stage.simulate()`에는 선택 인자 `controller`를 추가했다. 기본 호출의 결과는 변경 전과 같다. 기존 제어기를 `StageBController`로 다시 구현해 돌린 640 V·1→25 kW 결과는 98.03760862264 A로, 인라인 구현과 일치한다.
