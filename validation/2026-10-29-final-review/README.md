# 최종 보고서 작성 전 최종 검토 근거(2026-10-29)

문서는 docs/45다. 검토자 여섯(별도 에이전트)의 지적을 다시 확인할 때 쓴 파일을 모았다. 모두 진단이며 판정이 아니다. 저장소의 검증 코드와 근거 파일은 바꾸지 않았다.

| 폴더 | 내용 |
|---|---|
| `diag/` | `p5_rdson_diag.py`·`.json`: P5 클램프 스위치(CAB530M12BM3) 온도의 R\_DS(on) 배율 민감도(E39 근거 파일의 최악 사건 손실로 계산, 최악 조합 고정 근사) |
| `sensitivity/` | `sens.py`·`sens.log`: E38 l1 조건에서 ④ 대 ⑤ 보조 손실의 민감도(⑤ 보조 강압기 셰딩, 자성체·스위칭 계수, Stage A 고정 손실). `boost.py`·`boost.log`: 전용 승압기 손실의 스위칭 주파수 의존 |
| `repro/` | 제출 검증 코드 복사본에서 다시 실행한 기록(E38 l1·l2, E39 reg, E39 선정 변형, E35 clamp·고장 한 사례, 상태 누수 시험)과 JSON 비교 도구 `jcmp.py`. 복사본 경로를 쓰는 드라이버 스크립트는 기록으로만 둔다 |
| `process/` | 기준·결과 커밋 순서(`elog.txt`·`tblog.txt`), 대체된 값 검색 결과(`hits.tsv`) |
