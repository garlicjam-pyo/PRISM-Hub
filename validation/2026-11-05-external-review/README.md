# 제출 전 외부 검토 대응(E43) 근거

판정 기준과 코드는 실행 전에 커밋했다(651c508). 정리 문서는 docs/48이다.

| 파일 | 내용 |
|---|---|
| `E43/loss.json` | (L) Stage A 출력용량 항에도 스위칭 배율을 준 E41·E42 민감도, W1·W2, 칸 판정과 변화, 확인 R1 |
| `E43/heat.json` | (H) 클램프 문턱 정확도 범위 전체의 C1·가지 에너지·스위치 온도, 자기 가열 가정 갱신 기록 |
| `E43/sens.json` | (S) 창 조정 144건 × 측정 변형 네 가지의 판정·보호 오동작 지표, 범위 (C), 채택 |
| `E43/bat.json` | (B) Stage C 일시 정지 동안 48 V 배터리 등가 계산과 요구 |
| `E43/run1_loss_bat.log` | loss·bat 실행 기록 |
| `E43/run1_heat_sens_failed.log` | heat 1차 실행(반환값 처리 누락으로 중단, 실행 경과) |
| `E43/run2_heat_sens.log` | heat·sens 실행 기록(heat 약 35분, sens 약 20분, 2코어) |

## 결과 요약

- (S) 측정 사양 S1(버스 0–600 V 16비트, 포화) 채택: 이상·S1 잡음·S1 + 오차 두 방향 모두 144/144, 보호 오동작 없음, 범위 600 V ≥ 1.1 × 516.3 V.
- (L) ④ 대 ⑤ −25.0 … +11.2 %(같은 수준 유지), ④ − ⑥ 4.3–33.0 W, 가치 지도 칸 판정 변화 0칸. 확인 R1 차 0 W.
- (H) 사양 팩·R2-W460 모두 문턱 정확도 범위 전체 통과(W460 자기 가열 가정 3,750 → 3,800 J).
- (B) E22 배터리 등가(20 mΩ)에서 48 V 41.6–45.7 V(36–52 V 안, ±2 % 미유지). 요구: OCV 44 V에서 R_b ≤ 57.6 mΩ, ≥ 139 A(12.4 ms).
