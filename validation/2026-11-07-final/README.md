| 파일 | 내용 |
|---|---|
| `E47/inj.json` | 검증기 오류 주입 결과. fcheck\_judge(해시 검사 없이)로 다섯 경우를 확인했다: 양쪽 같은 행 삭제, 양쪽 같은 행 복제, 주파수 NaN, 주파수 20 kHz, 한쪽 첨두 +10 A. 다섯 경우 모두 실패로 검출됐다. fcheck\_s2로는 정상 결과가 통과하고, 양쪽 같은 첨두 +10 A는 기준 해시 불일치로 실패했다. E44 \_diff\_tree는 키 삭제와 배열 길이 변경을 차이로 잡았다. |
| `E47/dsx.json` | E45 dstrict를 결과 폴더 복사본에서 자식 프로세스로 실행했다. 그대로면 종료 0, E43 loss의 키 하나를 지우면 종료 1이다. |

**줄바꿈 정규화 규칙.** 저장소는 텍스트 파일을 LF로 배포한다(`.gitattributes`의 `* text=auto eol=lf`). 작업 사본은 Windows에서 CRLF일 수 있으므로 텍스트 입력은 CRLF를 LF로 바꾼 바이트의 SHA-256(`sha256_lf`)으로 대조한다. 원시 바이트 해시(`sha256`)는 그 실행 환경의 기록으로만 쓴다.
