# 요구사항·부하 등급·수락 기준 확정 근거 (2026-09-28)

[docs/14](../../docs/14_요구사항_부하등급_수락기준.md)에 쓴 수치의 근거 파일이다. 기준은 `final-report` 브랜치(b9bb8c0)의 유한 링크 6상태 평균모델과 고정이득 공통 제어기이며, **Python 단독 계산**이다(MATLAB 교차검증 예정).

| 파일 | 내용 | 생성 |
|---|---|---|
| static_requirements.json | R1: 비조정 V_A와 부하 입력범위, ISO 21498-1 B_420, ISO 21780 48 V 비교, 창 조정 변형 ③′의 처리전력. R3: 정적 최소 배터리 전압(링크 90 V, R +10 %), 저하 한계(버스 기준 384·390 V) | `python python/req_static.py` |
| dynamic_requirements.json | Tier-1(±10 kW, 90 A)·Tier-2(1↔25 kW, 93.75 A, 384–416 V) 격자 552건(공칭·지연 +3.0 µs는 7개 전압, 공차·민감도 16종은 640/920 V), 공칭 동적 최소전압 | `python python/req_dynamic.py` |
| delay_tier1.json | Tier-1 대표 스텝 3종의 전달지연 경계(640/920 V, 공칭 파라미터, 5.8–8.0 µs, 적분 0.1 µs) | `python python/req_delay.py` |
| contract_sequences.json | 부하 계약의 최악 시퀀스(12.7→25 kW 상승, 25→−3.2 kW 하강; 연속 램프와 1 ms 계단) 36건 | `python python/req_sequence.py` |
| sals_contract.json | SALS 계약 시험 200회 × 20 s: 관리 없음·정적 예약·SALS 비교, 메시지 지연 1–5 ms, 절반은 손실 0–20 % | `python python/sals_contract.py 200` |

`pprc_two_stage.simulate()`에는 선택 인자 `power_fn`(시간에 따른 부하 프로파일)만 추가했다. 기본 호출의 결과는 변경 전과 같으며, 640 V·1→25 kW 경로 피크 98.03760862264 A로 확인했다.
