# DAB 고장 모드 변조(E20)와 회로 확인(TB10) 근거 (2026-10-24)

이 폴더는 [docs/25](../../docs/25_DAB_고장모드변조_E20_TB10.md)의 근거 파일이다.

- **E20 파일.** 평균모델·해석 코드는 `submission/verification_code`의 `E20_dab_fault_modulation.py`와 공용 모듈 `dab_modulation.py`다. 아래 E20 파일은 그 실행 결과(`results/E20`)를 옮긴 것이다.
- **지령표.** 지령표 원본(`results/E20/eps_table.json`, 약 1 MB)은 `E20_dab_fault_modulation.py table`이 다시 만든다. 회로가 쓰는 j ≤ 0 부분은 TB10 `ref/TB10_eps_table.json`이다.
- **TB10 파일.** 회로 모델은 [TB10](../../simulink/tb/TB10_R2_FaultMod/README.md)이다. 아래 TB10 파일은 그 결과 요약을 옮긴 것이고, 주기 통계와 그림은 TB10 `results/`에 있다.

E20의 DAB 첨두는 정상상태 파형의 정확한 구간 선형 해석이다(이상 소자, 데드타임 없음). E17 평균모델의 궤적(버스·링크전압, DAB 지령 전류)마다 이 해석으로 계산했다. TB10은 TB09와 같은 소자 수준 스위칭 회로(게이트 격자 2.5 ns)에 EPS 게이트 생성기를 넣은 것이다. 분리·감발 시간은 3 ms로 줄였다.
