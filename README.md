## 현재 아키텍처 후보

```text
HV 배터리 ↔ Stage A: 2:1 공진 SC ↔ V_A 노드 ↔ 직렬 보상 포트 ↔ 400 V 보조 버스
                                  ↑                              │
                            400 V급 충전기                       ├─ 400 V 부하
                                                                 └─ Stage C → 48 V → 12 V

400 V 보조 버스 ↔ 절연 DAB ↔ 부유 100 V 링크 ↔ H-브리지 + LC ↔ 직렬 보상 포트
```

충전기는 Stage A 출력 노드에 연결하고 보조 부하는 직렬 조정 셀 뒤에 두는 후보 구성이다. 충전 전류가 직렬 셀을 통과하지 않으므로 기존 충전 바이패스 스위치를 폐지하는 방향이다. **충전기와 보조 버스의 동시 동작·전이는 아직 통합 시험하지 않았다.**

| 항목 | 현재 정의 | 검증 범위 |
|---|---|---|
| Stage A | 2:1 RSC, 4모듈×2위상, 150 kW 목표 | ±375 A ZCS ODE, MATLAB/Python; 하드웨어 미검증 |
| Stage B DAB | 8 kW 링크 측, 100 V·80 A, 4:1, 200 kHz, 11.1 µH | 전압에 따른 SPS 제한·방향별 96% 효율 근사 |
| 직렬 포트 | ±90 V, 경로·브리지 정격 100 A | H-브리지·필터 평균 모델; 전류 지령 ±84 A 후보 |
| 새 저장소자 | 링크 2 mF, 브리지 필터 5 µH, 직렬 100 µF, 버스 400 µF | 잠정 모델값; 부품·리플·열 설계 미완료 |
| Stage C | 48 V 3 kW와 12 V 1.5 kW를 위한 CLLC 5 kW 후보 | 기존 구현은 3 kW. 5 kW 재설계·회생 폐루프 미완료 |
| 보조 버스 정격 | 400 V·25 kW | 버스 부하 62.5 A와 직렬 경로 100 A를 구별 |

## 최신 결과

**후속 공통 제어기:** 운전점별 이득 재계산을 없앤 고정 이득 후보(극배치 파라미터 4.8 kHz)로 시험했다. 정격 내 60 A 상당의 1→25 kW 부하 증가 32개 전압점과 부하 제거·회생 등을 포함한 정상 41건, 한 변수씩 ±10% 바꾼 공차 28건을 통과했다. 정상 조건의 최악 전압 강하는 5.077 V, 경로 피크는 98.038 A, 회복시간은 353 µs다. 공차 조건의 경로 피크는 99.947 A로 실물 여유가 부족하다. **640 V의 5→29 kW와 전달 지연 10/15 µs는 실패**하므로 전 조건 보장은 아니다. Python/MATLAB의 80개 조건 판정은 모두 일치했다.

아래 표는 이전 운전점별 제어기 검증 이력이다. 최신 판정은 위 [공통 제어기 보고서](docs/11_공통제어기_60A_검증.md)를 우선한다.

| 시험 | 결과 | 해석 |
|---|---|---|
| 640/648/788/907/920 V, 5→25 kW | droop 5.08/4.97/3.83/3.70/3.69 V | 시험한 5점에서 전압·포트 제한 통과 |
| 동일 640 V 시험, 전류 지령 100 A | 경로 피크 **106.92 A** | 전압 회복만으로 정격 합격 판정 불가 |
| ±84 A 지령 후보, 640 V | 경로 피크 96.80 A | 공차·보호 지연에 대한 보장은 별도 필요 |
| 부하 제거·회생·0 V 직렬 포트 통과 | 추가 5사례 통과 | 평균 모델 범위 |
| 648 V, 20→36 kW 과부하 | 전압·전류 기준 실패 | 실패를 검출하는 회귀시험 포함 |
| 2단 모델 MATLAB/Python 비교 | 지표 최대 차이 1.91×10⁻¹⁰ | 같은 제어 이득, 독립 식 구현·적분 |
| SALS 관측 전 부하 발생 | **122.161 A, 10 ms 초과** | v0.9 창 수정만으로 강건성 미보장 |

SALS의 현재 개발 코드는 정격·정상상태 전력수지로부터 승인 예산을 계산하는 **단일 시점 우선순위 승인 로직**이다. 관측 전 사건에 대한 계약이 없거나 필수 부하만으로 예산을 초과하면 불가능 상태를 반환한다. 15 ms LP의 성능 우월성, 300회 전압 붕괴 없음, 하드웨어 증대와 동등하다는 기존 주장은 채택하지 않는다.

## 재현

새 공통 제어기: `python python/validate_fixed_control.py` → MATLAB의 `cd matlab; validate_fixed_control` → `python python/compare_fixed_control.py`. 상세 조건은 [새 검증 폴더](validation/2026-09-22-fixed-control/README.md)에 있다. 아래는 기존 2단 모델 재현이다.

Python은 NumPy, SciPy, Matplotlib가 필요하다. 저장소 루트에서:

```sh
python python/validate_two_stage.py
python python/validate_sals_contract.py
```

MATLAB R2024b에서 `cd matlab; validate_two_stage`를 실행한 뒤:

```sh
python python/compare_two_stage.py
```

역방향 ZCS·기존 이상 PPRC·충전기 상한 회귀시험은 [이전 실행 절차](validation/2026-09-22/README.md)를 따른다. `tb_b_pprc2.py`는 이상 직렬 포트, `tb_b_pprc3.py`는 링크 동특성을 생략한 v0.9 모델, `pprc_two_stage.py`는 유한 링크와 H-브리지 필터를 포함한 후보이다. 서로 다른 결과를 한 모델의 개선 수치로 섞지 않는다.

## 논문·신규성

고정비 STC+부분전력 조정, 양극성 직렬 PPC, 차량 우선순위 부하 관리는 선행기술이 있다. **현재 아이디어의 유일성은 입증되지 않았다.** 첨부본의 GM 특허 표기는 NIO로 정정했다. [후속 레퍼런스 확인](docs/10_검토대응_통합개발.md#6-레퍼런스-재확인과-논문-초고)과 [논문 1 초고](docs/06_논문1_초고_EN.md), [논문 2 초고](docs/07_논문2_초고_EN.md)는 실제 증거 수준에 맞춰 수정했다. 기존 효율·부피 우월성 표는 공정한 비교군과 새 부품 손실을 반영하기 전까지 확정 결과로 사용하지 않는다.
