# PRISM-Hub 졸업작품 논문(학회 2단 양식)

114쪽 최종 보고서(`../tex`)를 국내 학술대회 2단 양식(한글, A4, 6쪽)으로 줄인 논문 원고다. 보고서는 그대로 두고 따로 유지한다.

## 빌드

```sh
./make.sh            # = latexmk -xelatex -interaction=nonstopmode -halt-on-error -outdir=build paper.tex
```

- 결과는 `build/paper.pdf`다. `build/`는 저장소에 올리지 않는다.
- 필요한 것: TeX Live(XeLaTeX, latexmk), `xetexko`, Noto Serif CJK KR·Noto Sans CJK KR 글꼴.
- 그림은 `figs/`와 저장소의 `docs/fig/report/` 파일을 읽는다(`\repo` = `../../..`). 저장소 전체가 있어야 빌드된다.

## 채울 곳

붉은 글씨(`\fillin{…}`)는 나중에 채울 자리다.

- 저자 이름 세 칸, 지도교수, 소속(대학·학과)
- 학과·학회에서 정한 양식(쪽수 제한, 머리말 문구, 참고문헌 형식)이 생기면 `paper.tex` 앞부분의 조판 설정만 바꾸면 된다.

## 작성 규칙

- 수치는 최종 보고서와 같은 값(최종 설계 A25R, 공정 기준 E41·E42)을 쓴다. 보고서가 바뀌면 논문도 같이 고친다.
- 본문에 저장소 경로·URL과 검증 근거 번호(E·TB 번호의 상세)는 최소한으로 두고, 상세는 보고서에 맡긴다.
- 부정적 결과(H5 기각, H2 부분 충족, A25 불통과, TB33 오동작 사례 불통과, 클램프 지연 0.5 µs 반례)와 “같은 수준” 판정을 빼거나 강하게 바꾸지 않는다.
- 6쪽을 넘으면 중복된 결과 설명부터 줄이고, H2의 분모(102/128·128/128)와 보호 지연 조건(1.0 µs 고정)은 표·표주에 남긴다.
