# Stage A 25 kHz 설계 수정안(A25R: C\_A 2.4 mF) 판정: 설계 단계, E35, TB27

- 문서 버전: v1.0 (2026-10-28)
- 관련 문서:
  - [docs/38](38_StageA25_재검증_E32_E33_TB26.md): A25 재검증. 과도 판정 대부분 불통과와 선택지(6.2절). 사용자는 "A25 수정안 재검증"을 골랐다.
  - [docs/39](39_부품정격표_E34.md): 부품 정격 표(A25 기준). V\_A 클램프 스위치(P5)는 이 문서에서 C\_A를 바꾼 뒤 다시 본다.
  - [docs/14](14_요구사항_부하등급_수락기준.md): 부하 과도 계약(D3, Tier-1 ±10 kW 계단)
  - [docs/20](20_종합보고서_아키텍처_설계검증.md): 종합 보고서
- 근거 파일: [validation/2026-10-28-stage-a-25k](../validation/2026-10-28-stage-a-25k/README.md)의 E35\_design, E35, TB27. 코드는 검증 코드 묶음의 E35\_a25r\_design(설계 단계)과 E35\_a25r\_verify(판정)다. 회로 모델은 [TB27](../simulink/tb/TB27_StageA25R_Integrated/README.md)이다.
- 검증 수준:
  - 설계 단계는 판정 시험이 아니다. 고칠 내용을 개발 사례로 골랐다.
  - 판정(E35·TB27)의 기준은 E28·E30·E33과 같다. 실행 전에 커밋했고 바꾸지 않았다.

## 1. 요약

**A25에 V\_A 노드 커패시터를 6배(400 µF → 2.4 mF)로 키운 A25R은 요구 안의 동특성 판정을 모델과 회로에서 모두 통과했다.** 손실 모델도 회로와 3 % 안에서 맞았다. 대가는 C\_A의 부피·비용이다. 요구 밖 조건(20 kW 순간 계단, 100 µs 충전 램프, 사전 기동 없는 충전)은 여전히 불통과다.

| 항목 | A25(E33·TB26) | A25R(E35·TB27) |
|---|---|---|
| 과도(요구 안: Tier-1 ±10 kW 계단 2, 버스 램프, 느린 충전 3) | 느린 충전 0/3·0/3 | **6/6·6/6** |
| 모듈 고장 | 16/16 | **16/16**(3모듈 충전 첨두 105.5 A, A25 119.6 A) |
| 정상 운전점 | 33/36·31/36 | 33/36·**36/36**(공칭 불통과는 정격 충전점 시작 과도 76.7 A, 마지막 10주기 74.3 A) |
| 요구 밖(정보) | — | 0/6·0/6 |
| 회로 | 3/3 불통과(C5 판정 방식) | **4/4 통과**(첨두 차 ≤ 2.2 A, V\_A 차 ≤ 0.06 V) |
| 손실 회로 대조(정격 충전 정상상태) | 판정 불가 | 회로 510.5 W, 모델 495.8 W(+3.0 %) |
| V\_A 클램프 스위치(보수 계산) | 29–40 kHz, 334–405 °C | 5.8–8.7 kHz, 145–193 °C(아직 불통과) |

- 설계 요구가 둘 바뀐다.
  - 충전 전 사전 기동과 충전전류 증가 램프가 100 µs에서 **600 µs**로 늘어난다. 25 kHz 공진 15주기로, 150 kHz 설계의 100 µs와 같은 주기 수다.
  - V\_A 노드 커패시터가 **2.4 mF**로 늘어난다.
- 부하 계단은 요구사항 문서의 계약(docs/14 D3: 1 ms 창 최대 +7.98·−9.3 kW, Tier-1 대표 시험 ±10 kW)으로 판정했다. 150 kHz부터 써 온 20 kW 순간 계단(MA·MG)은 계약 밖이다. 정보로 계산했고 불통과였다.

## 2. 왜 필요한가

docs/38에서 A25의 문제는 공진이 6배 느려졌는데 나머지 시간 척도가 그대로라는 점이었다. V\_A 노드 커패시터, 충전기 램프, 관리기 반응 속도가 여기에 해당한다. 사용자가 A25를 고쳐 다시 판정하기로 정했다(2026-10-28).

고칠 내용은 판정 기준을 고정하기 전에 개발 사례로 골랐다. 판정 사례와 기준은 E33과 같게 두었다. 고칠 내용을 고르는 데 쓴 사례(느린 충전 3, Tier-1 계단 2)는 판정 사례에도 들어 있다. 그래서 판정 사례 가운데 새로 확인한 것은 정상점 72점, 고장 16, 버스 램프, 공차 표본 1, 회로 4사례다. 이 점은 한계로 적는다(7절).

## 3. 설계 단계(판정 아님)

| 후보 | 내용 | 결과(개발 사례) |
|---|---|---|
| D1 | 충전 요청 중 위상 셰딩 정지 | 느린 충전 위반 1번씩 남음, V\_A가 전부 켬보다 1.7 V 벗어남 |
| TM 하나씩 | 관리기 시간 상수(tau, t\_dwell, tau\_m, t\_lock, t\_hold) 하나를 150 kHz 값으로 | 다섯 경우 모두 불통과(tau\_m·t\_lock·t\_hold는 결과 같음) |
| TM1 | 다섯 개 모두 150 kHz 값 | MC는 통과, MD·ME 불통과(위반 4–5번). 20 kW 계단에서는 모듈을 4개까지 연달아 추가 |
| D4 | 막혔다 풀린 위상을 동작 위상의 인터리빙 자리에 맞춰 시작 | 불통과 |
| D1 + D4 | 둘 다 | MC는 T3만(1.02 V), ME 첨두 91.5 A로 악화 |
| **CA6** | **C\_A 2.4 mF** | **느린 충전 3사례, Tier-1 계단 2사례 모두 통과** |
| D3 | 부하 계단을 docs/14 계약(Tier-1 ±10 kW)으로 | A25 그대로도 통과 |

- 결과를 보면 원인은 관리기 논리보다 V\_A 노드의 시간 척도다. 공진 한 주기 동안 V\_A 노드가 받는 전하 교란을 C\_A가 150 kHz 설계와 같은 비율로 흡수해야 한다.
- 모델의 선택 인자 둘(충전 중 셰딩 정지 `chg_noshed`, 인터리빙 맞춤 시작 `align_start`)은 채택하지 않았다. 코드에는 남겼다(기본 꺼짐, 이전 결과와 같음).

### 4.2 모듈 고장, 정상 운전점

- 모듈 고장: 주행·충전 × 공칭·표본 1이 16/16 통과했다. 3모듈 충전 위상 첨두는 최대 105.5 A(정상 97.9 A, 분담 최대 1.084)였다.
- 정상 운전점: 공칭은 33/36이다. 정격 충전점 3점의 S4가 불통과였다. 시작 유지 뒤 첨두는 76.7 A이고 마지막 10주기는 74.3 A였다. E28·E33과 같은 시작 과도다. 표본 1은 36/36이다.

### 4.3 요구 밖(정보)

| 사례 | 결과 |
|---|---|
| MA 540 V 5 → 25 kW 순간 계단 | 첨두 87.1·88.2 A(T2), V\_A(T3) |
| MG 1008 V 25 → 5 → 25 kW | 모듈 추가 1번(T4) |
| MC·MD·ME 100 µs 충전 | 턴오프 위반 12–22번(최대 2.9–3.8 A) |
| MF 사전 기동 없는 충전 | 첨두 217–221 A(A25 169 A) |

- MF가 A25보다 나빠졌다. C\_A가 크면 충전기 전류가 V\_A를 늦게 올리고, 모듈 추가 판단도 늦어진다. 사전 기동 요구는 더 중요해졌다.

### 4.4 충전 중 정지 클램프(E26 사건 32개, C\_A 2.4 mF)

| 항목 | A25(C\_A 400 µF, docs/39) | A25R(2.4 mF) |
|---|---|---|
| V\_A 최고 | 469.4 V | 468.2 V |
| 사건 에너지 | 최대 6,987 J | 최대 6,981 J |
| 클램프 스위칭 | 29–40 kHz, 사건당 853–1,599번 | 5.8–8.7 kHz, 사건당 169–347번 |
| IGBT 에너지·온도(보수) | 64–131 J, 334–405 °C | 18–49 J, 145–193 °C |
| 판정(E34 P5) | 불통과 | 불통과(온도, 전류 468 A > 450 A) |

- C\_A를 키우면 클램프 스위칭이 1/5로 준다. 정상 열저항으로 본 보수 계산은 아직 150 °C를 넘는다. 사건은 7–32 ms로 짧다. Z\_th 곡선으로 다시 계산하면 통과할 수 있다. 전류 여유(0.5 × I\_CRM)는 그대로 넘는다.

- 모델과 위상 첨두는 MC27에서 +2.2 A, 나머지는 0.5 A 안이었다. V\_A는 0.06 V 안, 모듈 수 전환 시각은 같았다.
- 손실 대조 창은 TB26 진단을 반영해 정했다. 실제 주기로 잰 20주기 창이고, 정상상태 사례에만 적용했다. 출력용량 손실(Q\_oss·V)을 포함한 A25 손실 모델이 정격 충전점에서 회로와 3 % 안이었다. E31(docs/37) 이후 손실 결론의 근거가 회로 수준에서 확인된 것이다.

## 6. 바뀌는 결론과 남은 일

| 항목 | 이전 | A25R |
|---|---|---|
| Stage A 설계 | 150 kHz(R1) → A25(docs/38) | **A25R: C4MS008075U2 2병렬, L\_r 864.6 nH, C\_fly 46.875 µF, C\_A 2.4 mF** |
| 충전 전 사전 기동·충전전류 램프 | ≥ 100 µs(docs/22·34) | **≥ 600 µs** |
| 부하 계단 판정 | 20 kW 순간 계단 | docs/14 D3 계약(±10 kW)으로 판정. 20 kW는 정보 |
| 손실(④ 보조 94.4 W, 충전 520–639 W, E32) | 모델 | 정격 충전점 회로 대조 +3.0 % |
| 클램프 스위치 | 29–40 kHz | 5.8–8.7 kHz, 보수 계산 불통과(Z\_th 확인 필요) |

남은 일:
1. **C\_A 2.4 mF 부품 정격.** 400–470 V급, 리플 전류(위상 리플 합)를 부품 정격 표에 넣는다.
2. **C\_fly 전류 밀도(docs/39 P2).** A25R에서도 그대로다. 공진용 고전류 필름·세라믹 후보를 대조해야 한다.
3. **클램프 스위치.** IGBT Z\_th 곡선 대조 또는 SiC 스위치, 전류 여유를 다시 본다.
4. **바이패스 소프트 투입 분담, 470 V 팩 접촉기**(docs/39 P6·P9).
5. A25R로 바뀐 값을 docs/20·21·30·34 결론에 반영한다(보조·충전 손실은 E32 값, 충전 요구 600 µs).

## 7. 한계

- 고칠 내용을 고르는 데 쓴 개발 사례 5개(느린 충전 3, Tier-1 계단 2)가 판정 사례에도 들어 있다. 판정 기준은 E33과 같고 바꾸지 않았지만, 그 5개는 독립 확인이 아니다. 독립 확인은 공차 표본 1, 정상점, 고장, 버스 램프, 회로 4사례다.
- C\_A는 이상 커패시터다. ESR·ESL과 부품 공차는 없다.
- 공차 표본은 공칭과 표본 1만 보았다.
- 정상 운전점의 시작 과도(정격 충전 S4)는 150 kHz 설계부터 남은 불통과다. 실제 기동 순서(사전 기동, 램프)에서는 과도 판정이 통과했다.
