## 요약

두 번째 통합 검토(2026-11-06, 13개 절, 검토자 수치·스크립트 별첨)는 H1 정격 분리, H4 부하 승인, H5 기각은 조사한 모델 범위에서 유지된다고 보았다. 대신 H2의 추가 지연, 충전 시작의 부하 조건, 충전 단자 정의, 48 V 조정 범위, 고장 부품 정격, 배포 검증기의 우회 경로를 고칠 것을 요구했다.

검토자 수치는 출처에 따라 세 가지로 나눠 확인했다.

1. **E46으로 다시 계산한 값.** 저장소 코드를 실행하거나 저장 결과를 다시 집계했다(아래 표의 ‘E46’ 행).
2. **저장 결과를 그대로 인용한 값.** 저장된 회로 요약이나 이전 근거 파일의 값을 읽어 확인했다. 예: TB14·TB15 출력 100 µs 평균 최대, E43 배터리 에너지, E11 판정 일치.
3. **검토자 대조로만 표기한 값.** 제조사 C\_oss 곡선과 Q\_oss 근사가 약 1 % 안에서 맞는다는 결과(13장)는 다시 계산하지 않았다. 원고에도 ‘검토자 대조’라고 적었다.

결론은 바뀌지 않았고, 실패 두 가지를 새로 기록했다.

- **H2:** 같은 E12 스위칭 모델에서 Tier-2 복합 공차 128개 조합에 추가 지연 +3 µs를 주면 **114/128**이다. 실패 14건은 모두 경로전류 순시 100.05–101.21 A이고, 링크 최대는 6.83 kW다. H2는 부분 충족 그대로이며, 가설 표에 이 결과를 정식 판정과 별도 행(‘H2 추가 시험’)으로 적었다.
- **H3:** 사전 기동과 600 µs 램프는 보조부하 15·25 kW에서 확인한 조건이다. 640 V에서 보조부하 0·1 kW이면 위상 첨두가 **78.63·78.74 A**로 E35 공칭 한도 74.53 A를 넘는다. C\_fly 45.0·42.75 µF에서도 76.06·76.56 A로 넘는다. H3 판정(보조부하 25 kW)은 유지하고, 부하 조건을 명시했다.
