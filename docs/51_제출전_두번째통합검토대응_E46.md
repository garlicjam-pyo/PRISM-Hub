## 요약

두 번째 통합 검토(2026-11-06, 13개 절, 검토자 수치·스크립트 별첨)는 H1 정격 분리, H4 부하 승인, H5 기각은 조사한 모델 범위에서 유지된다고 보고, H2의 추가 지연, 충전 시작의 부하 조건, 충전 단자 정의, 48 V 조정 범위, 고장 부품 정격, 배포 검증기의 우회 경로를 고칠 것을 요구했다. 검토자 수치는 모두 저장소 코드·저장 결과로 다시 계산해 같은 값을 얻었다. 새 계산이 필요한 항목은 판정 기준과 코드를 먼저 커밋하고(E46) 실행했다. 결론이 바뀐 것은 없고, 실패 두 가지를 새로 기록했다.

- **H2:** 같은 E12 스위칭 모델의 Tier-2 복합 공차 128개 조합에 추가 지연 +3 µs를 주면 **114/128**(실패 14건 모두 경로전류 순시 100.05–101.21 A, 링크 최대 6.83 kW). H2는 부분 충족 그대로이며 이 결과를 별도 행으로 기록했다.
- **H3:** 사전 기동·600 µs 램프는 보조부하 15·25 kW에서 확인한 조건이다. 640 V·보조부하 0·1 kW에서는 위상 첨두 **78.63·78.74 A**로 E35 공칭 한도 74.53 A를 넘는다(C\_fly 45.0·42.75 µF에서도 76.06·76.56 A). H3 판정(보조부하 25 kW)은 유지하고 부하 조건을 명시했다.
- **충전 단자:** 원고의 216s 150.588 kW·373.542 A는 V\_A 앞에 별도 3 mΩ 경로를 둔 정의였다. 충전기 직결 단자 V\_A(R\_A 2.25 mΩ)로 통일해 **150.166 kW·374.585 A(8위상)**, 180–240s 125.19–166.82 kW로 고치고 그림 7-1(d)를 다시 그렸다.
- **검증기:** E45 fcheck가 양쪽 같은 행 삭제·제어 주파수 변경을 통과시키고, 필수 판정 실패에도 종료 코드 0을 냈다. 클램프 재개 키는 열저항을 반영하지 않았다. 모두 고치고 오류 주입으로 확인했다.

## 1. 사전 등록과 실행 경과

- **사전 등록(19e4e6b).** 판정 기준, 부분별 계산, 검증기 수정(fcheck\_judge, gate 판정, 종료 코드)을 실행 전에 커밋했다. 이어서 nc(비도통 항 운전점 의존)와 vmap2 (c) 점 집합 정정(de4a064), fig(그림 7-1(d), d67b7cc)를 실행 전에 추가 등록했다.
- **등록 전 시험 실행(공개).** 코드 디버깅을 위해 저장 자료 재집계 부분(power, h1, h2s, h4, tb25, e31, tb15, prot, loss, gate, cache)을 등록 전에 실행해 보았다. 이 부분들은 새 물리 계산이 아니라 저장 결과의 재집계이며 기준은 바꾸지 않았다. 새 계산 부분(h2d, ramp, c22의 CV·응답, vmap2의 경로·누설 L, nc, fig)은 등록 뒤 실행 결과만 쓴다.
- **vmap2 (c) 1차 실행.** 등록 코드의 누설 L 점검이 팩별 창 정격 대신 고정 정격을 쓰고 사양 팩을 빠뜨려 141점이었다(성립 변화 0). E18 `window_rating_W`와 사양 팩을 넣어 168점(변화 0)으로 다시 계산했고 1차 결과는 `vmap2.json`의 `ldab_run1`에 보관했다.
- **fig 1차 실행.** 사양 팩(충전 행 없음)에서 멈췄다. 숫자 팩만 그리도록 고쳐 다시 실행했다(118d6cd). ldab는 다시 실행해도 1차 기록을 덮지 않게 고쳤고, nc·ldab·fig를 다시 실행해(run2) 결과 파일이 같음을 확인했다.
- **전체 실행.** run1(power … h2d, 2작업자, 종료 0), run2(nc·ldab·fig, 종료 0). 필수 판정 실패 0.

## 2. 검증기와 재개 키(V02·V03)

- **fcheck\_judge.** 필수 56키(사례 12·고장 16 × 두 C\_fly), 사례·시드 이름 목록, 등록한 제어·플랜트 주파수(F-a 25,515.63 Hz 두 값, F-b 25,515.63·26,178.48 Hz), 행별 엄격 비교를 모두 요구한다. 계산 방식(`compute_pool`)과 재판정 방식(`judge_pool`)을 따로 저장한다.
- **종료 코드.** `common.verdict(..., gate=True)`의 실패를 모아 실행 끝에 종료 코드 1을 낸다(E45 S1·S2, E46 필수 판정).
- **재개 키.** E44 클램프 재개 키에 E44·E26·E39·E40·E38·E34·common 코드, `../data` 아래 모든 파일, E43 열 결과, 선택 소자(sw)·다이오드(vd)·T\_case를 넣었다.
- **실행 모드 기록.** E45 repro가 `PRISM_POOL=serial`을 되돌리지 않아 F 56행 물리 계산이 serial이었다(docs/50 정정). repro는 환경을 복원하고, fcheck는 계산 방식을 `_meta`에 기록한다.
- **E18 누설 L.** 정적 포트 검사에서 권선비와 함께 L\_dab = 11.1·(V\_W/400)² µH를 갱신한다(W410 11.662 µH, W460 14.680 µH).
