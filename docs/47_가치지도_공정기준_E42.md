# 47. 가치 지도의 공정 기준 재계산(E42)

작성 2026-11-03 · 검증 코드 E42(`E42_value_map_fair.py`) · 근거 파일 validation/2026-11-03-value-map-fair

〔후속 판정 2026-11-06, E45([docs/50](50_제출전_통합수정안대응_E45.md))〕 `judge_cells`가 같은 수준 후보를 경우별 실제 최소(bt)가 아니라 명목 최소 구조(b)와 비교해, E44 정정 뒤 B470 200s에 R2-W410이 더해졌다. 경우별 실제 최소와 비교한 재분류(판정 규칙 사전 커밋 5918311)에서 R2-W410은 어느 경우에도 최소가 아니고 해당 경우 최소와의 차가 최소 4.51 %여서 빠졌다(B470 200s: ①·④ 같은 수준). 나머지 13칸은 같다. 이 문서와 원시 JSON은 원래 결과로 보존한다.

〔정정 2026-11-06, E44([docs/49](49_제출전_재검토대응_E44.md))〕 비교 소자 E\_oss 조건 정정으로 ① 열이 약 1.4–2.0 W 줄었다(사양 팩 102.1 → 100.2 W). 칸 분류는 14칸 모두 같고, B470 200·216s·사양 팩의 명목 최소가 ④ → ①, B470 200s의 같은 수준 후보에 R2-W410이 더해졌다. B420 최선 칸 여유는 ≥ 13.4 %.

## 요약

최종 보고서의 독립 검토(2026-11-03)가 기여 2와 결론 Q3의 근거인 가치 지도(E18·E36·E38)에서 비교 조건 하나를 찾았다. 가치 지도의 ①(전전력 승압기 + 보조 강압기)은 ⑤와 같은 보조 강압기(25 kW, 2위상)를 경부하 셰딩 없이 두었고, ④·R2-W의 Stage A는 설계된 셰딩(I\_off 20 A)을 썼다. E41(docs/46 5절)이 ④ 대 ⑤에서 바로잡은 것과 같은 불공정이다. 사용자 결정(2026-11-03)에 따라 판정 기준을 실행 전에 커밋하고(bb6a2ce) 다시 계산했다.

| 항목 | 이전(E38 l1, 셰딩 없음) | E42(공정 기준) |
|---|---|---|
| ① 보조 평균(사양 팩) | 115.9 W | 102.1 W(= E41 ⑤) |
| 창 조정 모듈이 최선인 칸 | B\_420 200s(R2-W410), B\_470 224·240s(R2-W460) | **없음.** 세 칸 모두 "같은 수준" |
| ④가 최선인 칸 | B\_470 180–216s·사양 팩, B\_420 180·192s | **없음.** 모두 ①과 "같은 수준"(차 0.1–1.4 %) |
| ①이 최선인 칸 | B\_420 216·224s·사양 팩 | 같음(모든 경우 여유 ≥ 11.6 %) |

- **창 조정 모듈의 보조 손실 이점은 성립하지 않는다.** 200s B\_420은 ①이 R2-W410보다 4.0 % 작고(민감도 −8.3 … +22.5 %), 224s B\_470은 ①이 R2-W460보다 0.9 % 작다(−13.5 … +21.4 %). 240s B\_470은 ①이 성립하지 않고 R2-W460이 ②보다 6.0 % 작지만 자성체 계수 × 0.5에서 0.4 % 크다.
- **기여 2와 Q3의 문구를 바꾼다.** 창 조정 모듈은 V\_A가 부품 상한을 넘는 팩에서 400 V급 부품을 쓰게 하는 성립 수단이고, 보조 손실은 같은 칸의 다른 성립 구조와 같은 수준이므로 손실을 이점으로 주장하지 않는다. 기여는 성립 조건과 고장 강등 순서다.
- **④ 대 ①도 E41의 ④ 대 ⑤와 같은 결론("같은 수준")이다.** 가치 지도는 이제 E41과 같은 비교 조건을 쓴다.

## 1. 왜 필요한가

E41은 ⑤의 보조 강압기에 이상적 셰딩을 주어 결론 2를 "같은 수준"으로 고쳤다. 그런데 ①의 보조 경로는 ⑤와 같은 강압기이고(E25), 가치 지도는 이 강압기를 셰딩 없이 계산한 E38 l1 값을 그대로 썼다. 최종 보고서 독립 검토가 이 불일치를 짚었다. ①과 창 조정 모듈의 차가 사양 팩 감소량(13.8 W)보다 작은 칸(B\_420 200s 9.0 W, B\_470 224s 13.1 W)이 기여 2의 근거였으므로 다시 계산해야 했다.

## 2. 방법과 판정 기준(실행 전에 고정, bb6a2ce)

- **기준 모델**: E38 l1의 가치 지도와 같다(E15 손실 규칙, E38 Stage C 모델·정격 규칙, A25R 확장 격자, E18 팩 등급·성립 조건·프로파일).
- **(F1) 공정 기준**: ①의 보조 강압기에 E41과 같은 이상적 셰딩(1·2위상 가운데 손실이 작은 쪽, 1위상은 P ≤ 12.5 kW). ②의 전전력 조정기는 모델에서 1위상이라 셰딩 대상이 없다. Stage A·Stage B는 설계된 운전 그대로.
- **(F2) 민감도**(공정 기준 위, 모든 구조에 같이): 자성체 × 0.5·× 2, 스위칭 × 0.7·× 1.5, 제어 손실 0, GaN 전이 × 2, ① 보조 강압기 25 kHz. E41의 Stage A 항목은 확장 전압 격자의 변형이 없어 넣지 않았다.
- **확인**: (R0) 셰딩을 끈 경우가 E38 l1과 손실 차 ≤ 1e-6 W·성립·최선 칸 같음, (R1) 공정 기준 사양 팩 ① = E41 ⑤ ± 0.05 W, (R2) 모든 경우의 성립 집합이 같음.
- **칸 판정**: 공정 기준 최소 구조가 모든 경우에 최소이고 다음 구조보다 3 %(E15 동등범위)를 넘게 작으면 "최선", 아니면 3 % 안이거나 최소가 바뀐 구조와 함께 "같은 수준"(최선으로 주장하지 않음). 성립 구조가 하나면 "유일 성립".
- **문구 규칙(W)**: 창 조정 모듈은 "최선" 칸만 "보조 손실 최선", "같은 수준" 칸은 "같은 수준", 해당 칸이 없으면 보조 손실 이점을 주장하지 않는다.

## 5. 한계

- E15·E18과 같은 설계 단계 추정이다. 이상적 셰딩은 ①에 유리한 쪽이다.
- Stage A 고정 손실 민감도(+20·30 %, 수동소자 저항 × 2)는 넣지 않았다. 넣으면 Stage A를 쓰는 구조(④·R2-W)가 불리해지는 쪽이다(E41에서 ④가 6.8–10.5 % 커짐).
- ①의 25 kHz 경우는 자성체 손실을 정격의 비율로 두어 자성체 크기 증가가 손실에 들어가지 않는다(①에 유리한 끝값).
