# MATLAB 재검증 진행 기록

2026-09-22. 기준: v0.7.0 독립 검토 후 MATLAB R2024b Update 8 실행. 기존 [독립 검토](reviews/2026-09-21/PRISM_Hub_종합검토.md)는 당시 버전의 기록으로 보존한다.

## 이번에 수정하고 실제 실행한 범위

1. `prism_design_params.m`의 미정의 `B.droop`를 제거하고 실제 계산한 SPS 전류 한계를 출력한다. MATLAB 실행으로 추가 발견한 주파수 스윕의 숫자 변수 `C`와 Stage C 구조체 충돌도 수정했다.
2. Stage A의 각 도통 펄스에서 전류가 충분히 형성될 때 실제 극성을 기록하고 그 극성에서0으로 돌아오는 순간을 검출한다. 검출 지연은 연속된 조건 만족 샘플에 적용한다. 정방향에 고정된 극성 가정을 제거했다. deadtime에 입력으로 돌아가는 전류의 부호도 수정했다.
3. PPRC 출력 버스에서 DAB가 가져가는 `v_ser*i_dab/V_bus` 항을 추가하고 정상상태·CPL 선형화·제어기 초기조건을 함께 수정했다. 에너지 수지와 수치 미분 Jacobian을 회귀시험으로 확인했다.
4. 기존11.1 µH·200 kHz·60° 설계를 유지하여400 V에서 출력전류 지령 상한을 약80.08 A로 반영했다. 버스 전압이 낮아지면 SPS 한계도 비례해 낮추고8 kW에 따른 지령 제한을 함께 적용한다. 이 모델은 여전히 이상 양극성 직렬 포트를 가정하며 실제 polarity stage나 DAB 손실을 구현한 것은 아니다.
5. 150 kW 충전 함수에375 A와150 kW의 동시 상한을 적용했다. 충전기 단자 전압 `a+b*I`와 일치하는 이차식으로 전력 제한 전류를 계산하고 로그의 전압·전류 시점을 맞췄다. 순간 보호 envelope를 가정한 평균 충전기이며 실제 EVSE 통신·보호 지연 검증은 아니다.
6. 커패시터 축소 스윕에서 안정한 설계가 없으면 `None` 결과를 기록하고 계속 실행한다. 존재하지 않는 제어기를 참조해 스크립트가 중단되는 문제를 수정했다.
7. 실제 실행 가능한 `prism_pprc_average_tb.slx`를 생성·컴파일·실행했다. 상태궤환, 적분기,5 µs sample/transport delay,80.08 A 및8 kW에 따른 지령 제한, CPL 스텝을 포함한다. 전압·실제 처리전력·전류의 한계는 실행 후에도 검사한다.

## 구현과 결과의 사용 범위

수정된 핵심 모델은 Python `pprc_model.py`/`tb_b_pprc2.py`와 MATLAB `prism_pprc_*`/`tb_b_pprc.m`이다. 기존 SALS, WP4.5, TB-S3~5, TB-B3 및 PI 참고 모델은 아직 이 공통 모델로 이전하지 않았다. 과거 모델에서 생성한 그림·JSON이 남아 있는 것은 수정 후 전체 합격의 근거가 아니다. `SALS.validated=false`로 파라미터에서도 미검증 상태를 표시했다.

입력 커패시터는500 V 단일 부품 사양을 사용할 수 없어 파라미터에100 µF/1200 V를 **잠정 정격**으로 지정했다. 실제 제품 선정, 직렬 균압 여부, 리플전류·수명·온도·체적 검증은 남아 있다. CLLC는3 kW를 임의로 확대하지 않고,48 V3 kW+12 V1.5 kW 동시 공급에 필요한4.554 kW와 비교해 `combined_rating_ok=false`를 명시적으로 반환한다.600 V 운전의 잘못된20 kW 디레이팅 값은 폐기했다. 출력전압 도달 가능 범위를 먼저 정해야 한다.

MATLAB 파라미터 파일의 CLLC FHA와 단순 Rs-L-C/CPL 식은 정정했다. 다른 CLLC 분석 스크립트의 식·손실 보완과 광범위 운전 검증은 이번 실행의 완료 범위에 포함하지 않는다.
