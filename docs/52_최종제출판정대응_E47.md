## 요약

최종 제출 판정(2026-11-07)은 핵심 수치와 가설 판정이 회로·코드·시험 자료로 뒷받침된다고 보았다. 다만 두 원고를 그대로 제출하는 것은 보류하고, 다음 네 가지를 요구했다.

1. **초록·요약의 시험 범위.** 서로 다른 모델의 관찰을 한 문장에 묶었으므로 나눠 적는다.
2. **고장 강등 문단.** 400 V 부하 분리 조건이 한 문단 안에서 서로 다르게 설명되어 있으므로 고친다.
3. **충전 중 과도시험.** 분모와 부하 스텝을 명시한다.
4. **E11 결론.** 표현을 한정한다.

검증 코드를 함께 제출할 경우의 남은 우회 경로와 입력 해시의 줄바꿈 의존도 지적했다.

지적은 저장소 자료로 모두 확인했다. 검증기 보완은 판정 기준과 코드를 먼저 커밋한 뒤(b881c83) E47로 오류 주입을 확인했다. 결론은 바뀌지 않았다.

## E47 결과(run1, 종료 0)

- **(inj) 오류 주입.**
  - 비교 함수 fcheck\_judge(해시 검사 없이)로 다섯 경우를 시험했다. 모두 실패로 검출됐다.

    | 오류 | 검출 사유 |
    |---|---|
    | 양쪽 같은 행 삭제 | 행 수 |
    | 양쪽 같은 행 복제 | 이름 중복(고유 11 / 행 12) |
    | 주파수 NaN | 유한 수 아님 |
    | 주파수 20 kHz | 등록 주파수와 다름 |
    | 한쪽 첨두 +10 A | 숫자 차 |

  - 전체 S2(fcheck\_s2)에서는 정상 결과가 통과했고, 양쪽 같은 첨두 +10 A는 기준 해시 불일치로 실패했다.
  - E44 \_diff\_tree는 키 삭제와 길이 변경을 잡고, 같은 값은 차이 0이었다.
- **(dsx)** E45 dstrict를 결과 폴더 복사본에서 자식 프로세스로 실행했다. 그대로면 종료 0, E43 loss의 키 하나를 지우면 종료 1이다.
- **(s2)** 보관된 E45 cfly\_refactor 56행을 해시로 확인한 기준 사본과 비교했다. 문제 0건, 차 0이다.
- **(cnt)** 위 표의 E36·TB28 수치다. Tier-2 +3 µs 정보 시험은 13/14(632 V 1건 불통과)다.
- **(hash)** TB28 CSV 세 개 모두 정규화 해시가 LF·CRLF에서 같다. E46 power.json의 원시 해시는 CRLF 바이트 값이다.
- **(fig)** 그림 7-1을 다시 그렸다. 바뀐 것은 (a) 축 이름뿐이고, 값은 E46과 같다.

## 원고 반영

- **논문.**
  - 한·영 초록 마지막 문장을 판정서 교체안대로 바꿨다. 25 kW 결합 회로 문장은 ‘두 전압이 허용 범위에 있었다’로 썼는데, TB28 A·B·C의 C1(V\_A·버스 ≤ 470 V)·C3(48 V ±2 %) 통과가 근거다.
  - 4.5절 충전 과도 분모·스텝, 4.6절 고장 강등 문단, TB27 4/4 분모, 그림 4 캡션 (a)를 고쳤다.
  - 검토 횟수를 아홉 차례로 바꿨다.
  - 6쪽을 유지하려고 다음 문장을 줄였다: E\_oss 정정 이력, 216s 위상 수 괄호, 스위치 온도 정의, 지연 간격 부가값, 정격점 효율 문장.
- **긴 원고.**
  - 요약의 연속성 항목을 세 시험 종류로 나눴다.
  - 5장 E11 표현, 8장 표(분모·스텝), 7장 그림 (a) 표주를 고쳤다.
  - 4장에 아홉 번째 검토를 추가하고, 18장 검토 표와 부록 C·표지(E1–E47)를 갱신했다.
- **쪽수.** 긴 원고 120쪽, 논문 6쪽이다. 미해결 참조·Overfull 0건이며, 본문 끝과 쪽 번호의 간격은 모두 충분하다(목차 쪽은 검사 대상 아님).

## 남은 일
