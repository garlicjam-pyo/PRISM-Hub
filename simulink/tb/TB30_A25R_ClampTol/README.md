# TB30 — 재선정 V\_A 클램프(저항 공차·온도계수·스위치 강하의 두 모서리) 회로 확인

**결론: 실행 뒤 적는다.**

## 왜 필요한가

외부 검토(2026-10-29)에서 TB29의 클램프 1.2 Ω는 공칭값만 확인했다는 지적을 받았다. 468 V에서 충전기 375 A를 흡수하려면 클램프 저항 전체가 470/375 = 1.253 Ω 이하여야 한다. 그런데 저항에는 공차·온도계수·노화가 있고, 배선 저항과 스위치 강하도 더해진다. E26 모델에서 1.26 Ω(+5 %)이면 32사건 가운데 12사건이 470 V를 넘었다.

E38 Q1은 Ohmite SP 저항(공차 ±10 %, 온도계수 +0.2/−0.08 %/°C, 노화 ±5 %)의 두 모서리로 클램프를 다시 골랐다. 한 가지 저항으로는 큰 모서리에서 전류가 모자라고 작은 모서리에서 스위치 전류가 넘쳐 성립하지 않았다. 선정은 **가지 2개 × 공칭 1.6 Ω(가지마다 SiC 스위치, 같은 게이트), 켬 468·끔 463 V**다. 이 TB는 두 모서리를 회로에서 확인한다.

## 회로

TB29와 같다(Stage A A25R 4모듈 + 충전기 + V\_A 클램프 + 400 V 버스·감쇠기 + 조정형 Stage C). 클램프만 다르다.

- 가지 2개는 같은 게이트로 함께 켜지므로 등가 가지 하나로 둔다. 저항은 모서리 가지 저항 ÷ 2다.
- 큰 저항 모서리에서는 스위치 강하 2.05 V를 직렬 직류 전원 `V_drop`으로 넣는다. 작은 저항 모서리에서는 0 V다.
- 클램프 스위치는 이상 스위치 셀(1 mΩ)이다. 스위치 손실·온도는 회로에서 계산하지 않는다(E38의 데이터시트 계산).

## 사례와 판정 기준(시험 전에 고정)

| 사례 | 조건(사건 1.5 ms, 400 V 부하·Stage C 0) |
|---|---|
| A30\_640V\_noload\_Rmax | 640 V, 충전 375 A, 배터리 경로 상실(8위상 차단), 충전기 3 ms 유지 뒤 0. 큰 저항 모서리(가지 2.340 Ω → 등가 1.170 Ω, 강하 2.05 V). E38에서 큰 저항일 때 버스 최고가 가장 높았던 사건과 같은 팩·부하·프로파일 |
| B30\_920V\_noload\_Rmin | 920 V, 같은 사건. 작은 저항 모서리(가지 1.190 Ω → 등가 0.595 Ω, 강하 0). E38에서 가지 전류가 가장 컸던 사건 |

| 기준 | 내용 |
|---|---|
| (C1) | V\_A·버스 1 µs 평균 ≤ 470 V(1 ms 이후). 순시 최고는 정보 |
| (C1r) | E26 대조(같은 모서리): V\_A·버스 1 µs 최고 ±1.5 V, 클램프 저항 흡수 에너지 ±10 %(또는 ±10 J) |
| (C3) | 48 V 10 µs 평균 ±2 %·E22 대조 ±0.5 V, Stage C 전류, ZVS(≤ 5 % 레일) |
| (C4) | 사건 전 Stage A: 8위상 턴오프 전류/피크 ≤ 5 %, 위상 전류 차 ≤ 5 %, V\_A − 모델 ≤ 0.3 V |
| (C5) | 1 ms 이후 모든 턴오프(사건 순간 강제 차단 제외): \|i\_off\| ≤ max(5 % × 반주기 첨두, 1 A) |

정보: 클램프 켬 횟수·켜진 시간(E26과 비교), 가지 전류 첨두(합 ÷ 2).

기준값은 `ref/make_ref_TB30.py`다(TB29와 같은 방법, 클램프 모서리만 다름. E38 결과 `clamp.json`에서 선정값을 읽는다).
