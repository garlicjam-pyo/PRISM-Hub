# TB29 — V\_A 클램프 저항 1.2 Ω(부품 정격 2차 설계 변경) 회로 확인

**결론: (실행 전)**

## 왜 필요한가

부품 정격 2차(E37, docs/42)에서 V\_A 클램프 스위치(1200 V IGBT 모듈 FF450R12ME4P)가 원설계(1 Ω, 468/463 V)로는 전류(468 A > 450 A)와 온도(193 °C)를 넘었다. 클램프 저항을 1.2 Ω로 바꾸면 전류는 390 A, 보수 계산 온도는 149 °C가 된다.

1.2 Ω에서는 468 V에서 클램프 전류(390 A)가 충전기 전류(375 A)보다 조금만 크다. 그래서 클램프가 V\_A를 내리는 속도가 느려지고 켜진 시간이 길어진다. 모델(E26 사건 32개)에서는 V\_A ≤ 470 V였다. 이 변경을 TB28 회로(A25R Stage A, 조정형 Stage C, 실제 클램프 스위치 셀)에서 다시 확인한다.

## 회로

TB28과 같다(Stage A A25R 4모듈 + 충전기 + V\_A 클램프 + 400 V 버스·감쇠기 + 조정형 Stage C). 클램프 저항 값만 1.2 Ω다(ref에서 읽음).

## 사례와 판정 기준(시험 전에 고정)

| 사례 | 조건(사건 1.5 ms) |
|---|---|
| A29\_920V\_pathloss | 920 V, 충전 375 A, 400 V 부하 20 kW + Stage C 5 kW. 배터리 경로 상실(8위상 차단). 충전기 3 ms 동안 375 A 유지 뒤 0 |
| B29\_640V\_pathloss | 640 V, 같은 부하·사건. E37에서 IGBT 온도가 가장 높았던 사건(R2 640 V, 20 + 5 kW, 유지)과 같은 팩·부하·프로파일 |

| 기준 | 내용 |
|---|---|
| (C1) | V\_A·버스 1 µs 평균 ≤ 470 V(1 ms 이후). 순시 최고는 정보 |
| (C1r) | E26 대조(클램프 1.2 Ω): V\_A·버스 1 µs 최고 ±1.5 V, 클램프 흡수 에너지 ±10 %(또는 ±10 J) |
| (C3) | 48 V 10 µs 평균 ±2 %·E22 대조 ±0.5 V, Stage C 전류(100 µs 평균 ≤ 136.5 A, 2차 소자 ≤ 329 A), ZVS(≤ 5 % 레일) |
| (C4) | 사건 전 Stage A: 8위상 턴오프 전류/피크 ≤ 5 %, 위상 전류 차 ≤ 5 %, V\_A − 모델 ≤ 0.3 V |
| (C5) | 1 ms 이후 모든 턴오프(사건 순간 강제 차단 제외): \|i\_off\| ≤ max(5 % × 반주기 첨두, 1 A) |

정보: 클램프 켬 횟수·켜진 시간(E26과 비교), 클램프 전류 첨두.

기준값은 `ref/make_ref_TB29.py`다(TB28과 같은 방법, 클램프 저항만 1.2 Ω).
