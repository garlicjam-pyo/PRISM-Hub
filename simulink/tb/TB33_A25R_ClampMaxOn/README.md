# TB33 — V\_A 클램프 최대 연속 켜짐 시간(E40) 회로 확인

**결론: 실행 전(판정 기준 고정).**

## 왜 필요한가

최종 검토(docs/45 A3)에서 클램프 문턱 오차가 낮은 쪽이면, 배터리 경로가 살아 있는 정상 충전 중 켜진 클램프가 꺼지지 않을 수 있음을 찾았다. 클램프가 켜지면 Stage A가 배터리에서 전류를 끌어 V\_A를 끔 문턱 아래에 붙잡기 때문이다. 그러면 저항에 수백 kW가 들어가 수십 ms 안에 15 kJ를 넘는다.

E40은 두 가지를 바꿨다.

- **설계 변경 M:** 클램프 게이트가 0.5 ms 동안 계속 켜져 있으면 끈다. 그 뒤는 보통 비교기 논리로 돌아간다.
- **클램프 재선정:** 전형값만 있는 손실 인자에 규칙 L을 적용해 다시 골랐다(docs/46).

평균모델(E26)에는 Stage A 동특성이 없다. 그래서 이 TB는 두 가지를 회로에서 확인한다.

- 오동작으로 클램프가 켜졌을 때 Stage A가 충전 방향에서 방전 방향으로 크게 바뀌는 전류를 견디는지.
- 최대 켜짐 시간이 회로에서도 클램프를 끄는지.

## 회로

TB32와 같다(Stage A A25R 4모듈 + 충전기 + V\_A 클램프 두 가지 묶음 + 400 V 버스·감쇠기 + 조정형 Stage C). 클램프 비교기만 `ctrl/prism_va_clamp_m.m`이다. 이 비교기에는 세 가지가 있다.

- E26과 같은 히스테리시스와 지연 1 µs.
- 최대 연속 켜짐 시간.
- 시험용 강제 켬 시각.

가지 1은 가지 하나이고, 가지 2는 나머지 n − 1개의 등가다. 저항값·강하·조합·문턱은 `ref/make_ref_TB33.py`가 E40 결과에서 읽는다.

## 사례와 판정 기준(시험 전에 고정)

| 사례 | 조건(400 V 부하·Stage C 0) |
|---|---|
| A33\_640V\_noload\_mix | 640 V, 충전 375 A, 1.5 ms 배터리 경로 상실(8위상 차단), 충전기 3 ms 유지 뒤 0, mix 조합(TB32 A32와 같은 사건) |
| B33\_920V\_noload\_mix | 920 V, 같은 사건, mix |
| C33\_920V\_spurious | 920 V, 충전 375 A, 배터리 경로 정상(Stage A 동작). 1.5 ms에 클램프 게이트 강제 켬, 문턱 × 0.99. 클램프가 켜지면 비상 정지가 나가 충전기가 3 ms 유지 뒤 0이 된다. 조합: E40 thr의 사양 팩 ε = −1 % 사건 가운데 강제 끔이 일어난 조합 중 가지 전류 최고가 가장 큰 조합 |

| 기준 | 내용 | 사례 |
|---|---|---|
| (C1) | V\_A·버스 1 µs 평균 ≤ 470 V(1 ms 이후) | 전부 |
| (C1r) | E26 대조: V\_A·버스 1 µs 최고 ±1.5 V, 클램프 저항 에너지 합 ±10 %(또는 ±10 J) | A·B |
| (C2b) | 가지 대조: 가지 전류 1 µs 최고 ±2 %(또는 ±5 A), 가지 저항 에너지 ±10 %(또는 ±10 J) | A·B |
| (C3) | 48 V 10 µs 평균 ±2 %·E22 대조 ±0.5 V, Stage C 전류, ZVS(≤ 5 % 레일) | 전부 |
| (C4) | 사건 전 Stage A: 8위상 턴오프 전류/피크 ≤ 5 %, 위상 전류 차 ≤ 5 %, V\_A − 모델 ≤ 0.3 V | 전부 |
| (C5) | 1 ms 이후 모든 턴오프(사건 순간 강제 차단 제외): \|i\_off\| ≤ max(5 % × 반주기 첨두, 1 A) | 전부 |
| (C6p) | 클램프 연속 켜짐 ≤ 최대 켜짐 시간 + 2 µs | A·B |
| (C6) | 강제 켬 뒤 연속 켜짐 ≤ 최대 켜짐 시간 + 2 µs, 꺼진 뒤 사건 끝까지 다시 켜지지 않음 | C |
| (C6e) | E26 대조: 클램프 저항 에너지 ±15 %(또는 ±10 J), 켜진 시간 ±5 µs | C |
| (C8) | Stage A 위상 첨두(1 ms 이후) ≤ 2 × 0.5 × I\_DM / 1.1 = 562.7 A(E34 P1 (I)를 위상으로 환산) | C |

정보로 보는 것:

- 클램프 켬 횟수·켜진 시간·강제 끔 횟수(E26과 비교), 가지 1의 에너지 몫.
- 사례 C의 V\_A 최저와 Stage A 출력전류 최고(E26 대조). E26의 Stage A는 저항 등가라 회로와 다를 수 있다.

## 재현

```matlab
prism_run('build_TB33')

```

기준값: `ref/make_ref_TB33.py <검증 코드 python 폴더> [E40 결과 폴더]`(E40 p5·thr 필요).

## 한계

TB32와 같다(충전기 이상 전류원, 충전기 정지 3 ms, 이상 클램프 스위치, 48 V 배터리 없음, 공칭 부품값). 오동작의 원인(문턱 오차와 과도·잡음)은 모의하지 않고 게이트를 강제로 켠다. 문턱 오차는 켬·끔에 같은 비율로 준다.
