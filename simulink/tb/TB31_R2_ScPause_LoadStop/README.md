# TB31 — Stage C 일시 정지(바이패스 소프트 투입)와 이중 고장 400 V 부하 정지(R2-W460)

**결론: 2/2 통과(2026-10-29).** Stage C 일시 정지가 있으면 H-브리지 개방 강등의 링크 붕괴가 링크 0.49 V까지 끝난 뒤 소프트 투입하고, 소자 에너지 0.0227 J·EPC2305 1개 105.0 °C였다(E38 모델 0.0214 J·104.7 °C). 이중 고장에서 400 V 부하 정지(3 ms)로 경로전류가 Stage A 정지 1.11 ms 뒤 1 A 아래가 되었다(모델 1.113 ms, 기준 5 ms). 상태 전이 시각은 모델과 0.035 ms 안이다. 1차 실행은 출력 단계의 구현 오류로 멈췄고, 고쳐 다시 실행했다(아래 실행 경과).

## 왜 필요한가

남은 설계 과제 두 가지의 원인은 모두 400 V 쪽 부하였다(docs/43).

- **P6 바이패스 소프트 투입**: H-브리지 고장 강등에서 남는 부하(Stage C 5.3 kW + V2L 3.8 kW)가 크면 경로전류가 다이오드로 링크에 계속 들어온다. DAB가 낮은 링크 전압에서 이 전류를 다 빼내지 못해 링크 붕괴가 시간 상한(10 ms)에 걸리고, 직렬 −25.7 V에서 소프트 투입한다. 소자 에너지 0.75 J의 대부분은 버스 커패시터(2 mF)를 25.7 V 올리는 충전 손실이다. 대책은 **붕괴·소프트 투입 동안 Stage C 일시 정지**다. Stage C는 허브 안 변환기라 통신 없이 멈출 수 있고, 48 V는 48 V 배터리가 맡는다.
- **F2 이중 고장 경로전류**: Stage A가 멈춘 뒤에도 400 V 부하가 버스를 저전압 차단(250 V)까지 끌어내리는 동안 경로전류가 남는다(W460 6.1–6.2 ms). 대책은 **이중 고장 때 전용 배선 신호로 400 V 부하 정지**다. 그러면 V\_A 노드 방전 저항이 필요 없다.

E38(평균모델)에서 두 대책을 판정했다. 이 TB는 TB23 회로에서 같은 순서를 확인한다.

## 회로

TB23과 같다(TB13 전력 회로·EPS 지령 블록·스위칭 반영 첨두 표·설계 상한 1.387 × 정격점, 등급별 계약 응답 부하, SALS 모드 상태기계, Stage A 정지 스위치). 다른 것은 다음과 같다.

| 블록 | 내용 |
|---|---|
| `R2_Supervisor` | `ctrl/prism_r2_supervisor.m` 파라미터 71개. 70: Stage C 일시 정지(붕괴 시작부터 강등 0.5 ms 뒤까지 비트 32), 71: 400 V 부하 정지(이중 고장에서 비트 64). 69개 이하면 이전과 같다 |
| `Load_CPL` | `ctrl/prism_sals_loads.m` 파라미터 23개. 비트 32이면 Stage C 입력(양의 전력)을 4 kW/ms로 0까지, 꺼지면 같은 변화율로 복귀. 비트 64이면 400 V 부하 전체를 23번째 파라미터의 램프로 0까지. 22개면 이전과 같다 |
