# TB31 — Stage C 일시 정지(바이패스 소프트 투입)와 이중 고장 400 V 부하 정지(R2-W460)

**결론: 실행 뒤 적는다.**

## 왜 필요한가

남은 설계 과제 두 가지의 원인은 모두 400 V 쪽 부하였다(docs/43).

- **P6 바이패스 소프트 투입**: H-브리지 고장 강등에서 남는 부하(Stage C 5.3 kW + V2L 3.8 kW)가 크면 경로전류가 다이오드로 링크에 계속 들어온다. DAB가 낮은 링크 전압에서 이 전류를 다 빼내지 못해 링크 붕괴가 시간 상한(10 ms)에 걸리고, 직렬 −25.7 V에서 소프트 투입한다. 소자 에너지 0.75 J의 대부분은 버스 커패시터(2 mF)를 25.7 V 올리는 충전 손실이다. 대책은 **붕괴·소프트 투입 동안 Stage C 일시 정지**다. Stage C는 허브 안 변환기라 통신 없이 멈출 수 있고, 48 V는 48 V 배터리가 맡는다.
- **F2 이중 고장 경로전류**: Stage A가 멈춘 뒤에도 400 V 부하가 버스를 저전압 차단(250 V)까지 끌어내리는 동안 경로전류가 남는다(W460 6.1–6.2 ms). 대책은 **이중 고장 때 전용 배선 신호로 400 V 부하 정지**다. 그러면 V\_A 노드 방전 저항이 필요 없다.

E38(평균모델)에서 두 대책을 판정했다. 이 TB는 TB23 회로에서 같은 순서를 확인한다.

## 회로

TB23과 같다(TB13 전력 회로·EPS 지령 블록·스위칭 반영 첨두 표·설계 상한 1.387 × 정격점, 등급별 계약 응답 부하, SALS 모드 상태기계, Stage A 정지 스위치). 다른 것은 다음과 같다.

| 블록 | 내용 |
|---|---|
| `R2_Supervisor` | `ctrl/prism_r2_supervisor.m` 파라미터 71개. 70: Stage C 일시 정지(붕괴 시작부터 강등 0.5 ms 뒤까지 비트 32), 71: 400 V 부하 정지(이중 고장에서 비트 64). 69개 이하면 이전과 같다 |
| `Load_CPL` | `ctrl/prism_sals_loads.m` 파라미터 23개. 비트 32이면 Stage C 입력(양의 전력)을 4 kW/ms로 0까지, 꺼지면 같은 변화율로 복귀. 비트 64이면 400 V 부하 전체를 23번째 파라미터의 램프로 0까지. 22개면 이전과 같다 |
| `C_A` | 2.4 mF(A25R). 이중 고장의 방전 저항 없음 |

부하 블록 함수는 검증 코드 `sals_loads.SalsLoads`와 무작위 40개 시나리오(일시 정지·재개·부하 정지 포함)로 대조한다(`ref/check_sals_parity31.m`, 기준 최대 차 ≤ 1 W).

## 사례와 판정 기준(시험 전에 고정)

SALS 시간은 TB23과 같이 0.15배로 줄인다(메시지 지연 5 → 0.75 ms, 접촉기 20 → 3 ms 등). Stage C 일시 정지(허브 내부, 4 kW/ms)와 부하 정지 램프(전용 배선)는 줄이지 않는다.

| 사례 | 조건 |
|---|---|
| A31\_930V\_MX\_S5\_pause | 930 V, 25 kW(Stage C 5.3 + V2L 3.8 + 컴프레서 6 + PTC 7 + 배터리 히터 2.9 kW), H-브리지 개방(0.5 ms), 메시지 지연 5 ms(축소 0.75 ms), Stage C 일시 정지. TB23 A와 같은 사건 |
| E31\_1008V\_dab\_double\_stop | 1008 V, 25 kW, DAB 고장 → 제동 유지 중(검출 0.5 ms 뒤) H-브리지 차단(이중 고장) → 접촉기 분리 + SALS 감발 + Stage A 정지(5 µs) + 링크 제동 저항 과전압 보호 + 400 V 부하 정지(E38 f2 선정 램프). TB23 E와 같은 사건 |

| 사례 | 기준 |
|---|---|
| A31 | TB23 A–D와 같은 회로 한계(순시 경로·필터 ≤ 100 A, \|v\_s\| ≤ 120 V, 링크 ≤ 120 V, 바이패스 ≤ 329 A, 버스 ≥ 260 V, 강등 상태 도달, 400 V 부하가 연결된 동안 버스 ≤ 상한, 강등 상태 9–11의 DAB 링크 쪽 순시 첨두 ≤ 1.5 × 정격점), 제동 ≤ 64 J, **(P6) 소프트 투입 소자 EPC2305 1개: 100 °C + ΔT(Foster Z\_thJC, 1 µs 평균 전력) ≤ 150 °C** |
| E31 | TB23 E와 같다: 순시 경로·필터 ≤ 100 A, \|v\_s\| ≤ 120 V, 링크 ≤ 120 V, 400 V 부하 연결 중 버스 ≤ 상한, 제동 ≤ 64 J, **Stage A 정지 뒤 5 ms 안에 경로전류(5 µs 평균) \|i\_p\| ≤ 1 A가 되어 끝까지 유지** |

정보(E38 대조): 상태 전이 시각, 주기 평균 버스·전류·링크, 부하 전력, 소프트 투입 에너지·시작 조건, Stage C 일시 정지·재개 시각, \|i\_p\| ≤ 1 A까지 시간.

기준값은 `ref/make_ref_TB31.py`다(E17 r2_run의 sc_pause·load_stop, 정지 램프는 E38 `f2.json`의 선정값).

## 한계

TB23과 같다(Stage A 등가 이상 전원, SALS 시간 축소, 이상 소자). Stage C 일시 정지 동안의 48 V 쪽(48 V 배터리가 부하를 맡음)은 이 회로에 없다. 부하 정지는 모든 400 V 부하가 같은 램프로 줄어든다고 둔다.
