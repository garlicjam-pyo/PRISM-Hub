# PRISM-Hub 검증 코드

800 V 전기자동차용 통합 직류 전력 허브(PRISM-Hub) 중간보고서의 **부록 C 검증 근거(E1–E10)** 와, 보고서 이후 진행한 **추가 검증(E11 채택 제어기 MATLAB 교차검증, E12 Stage B 스위칭 모델 검증, E13 기준 구조 ③′·④ 평균모델 비교, E14 Stage B 보호·기동, E15 기준 구조 손실·정격 비교, E16 충전 중 보조버스)** 을 계산한 MATLAB·Python 코드다. 근거 번호별로 스크립트를 하나씩 두었고, 각 스크립트 머리말에 **목적 · 왜 필요한가 · 방법 · 판정 기준 · 실행 방법 · 결과 파일 · 보고서 수치**를 한글로 적었다. 본문 주석도 한글이다.

모든 결과는 **시뮬레이션**(스위칭 ODE 모델, 스위칭 주기 평균모델, 1 ms 축약 부하 모델)이며 하드웨어 측정이 아니다.

## 2. 실행 환경

| 항목 | 확인한 환경 |
|---|---|
| Python | 3.11, NumPy 2.4, SciPy 1.17, Matplotlib 3.10, Numba 0.68 (`pip install -r requirements.txt`) |
| MATLAB | R2024b(보고서 수치). 추가 툴박스 불필요 |
| GNU Octave | 8.4 (MATLAB 스크립트 호환 확인용) |

한글 그림 라벨은 Malgun Gothic, AppleGothic, NanumGothic, Noto Sans CJK 중 설치된 글꼴을 자동으로 쓴다.

## 3. 실행 순서

```bash
cd python
python run_all.py                 # E1–E16 전체 (2코어 기준 약 5시간, 그중 E12 약 3시간)
python E3_steady_state.py         # 개별 실행 예
python E5_E7_controller.py grid --design reference   # 제어기 파트·설계 선택
```

MATLAB 교차검증(E2)은 Python E2a·E2b가 만든 사례 파일을 읽는다.

```matlab
cd matlab
E1_stage_a_zcs            % [E1]
E2_two_stage_crosscheck   % [E2]  python/E2a, E2b 실행 후
E10_stage_c_cllc          % [E10]
E11_controller_crosscheck % [E11]  python/E11_controller_crosscheck.py export 실행 후
```

그다음 `python E2c_compare_matlab.py`, `python E11_controller_crosscheck.py compare`로 두 구현을 대조한다. 병렬 작업 수는 환경변수 `PRISM_WORKERS`로 바꿀 수 있다.

## 5. 공통 모델 요약

**Stage A 스위칭 ODE (`model_stage_a.py`, `prism_sim_array.m`)** 위상마다 공진전류와 플라잉 커패시터 전압을 상태로 두고 충전·방전·데드타임 구간을 스위칭 순간 그대로 RK4로 적분한다(주기당 340단계). 타이밍은 고정 주기(`fixed`)와 위상별 영교차 추종(`zcp`, 블랭킹 창 0.80–1.12배)을 비교한다. 공차 난수는 MATLAB `rng(seed); rand(...)`와 같은 Mersenne Twister 열을 쓰므로 Python과 MATLAB이 같은 부품 표본으로 시험한다.

**Stage B 평균모델 (`model_stage_b.py`, `prism_two_stage_case.m`)** 상태 [i_p, v_s, v_bus, i_h, v_link, i_dab]의 6상태 유한 링크 평균모델이다. 제어 갱신 5 µs(영차유지), 전달지연 5 µs, DAB 응답 10 µs를 모델 안에 두고, 모델 밖 지연 예산 3.0 µs를 추가 지연 시험으로 다룬다. 적분은 명시적 중점법(0.2 µs, 지연이 0.2 µs의 배수가 아니면 0.1 µs)이다. 제어기는 공칭 파라미터만 알고 플랜트 공차를 모른다. 포트 한계(경로·필터 100 A, 링크 80 A·8 kW, 직렬 ±90 V, 링크 90–110 V, 변조율 ±0.95)는 실제 상태를 제한하지 않고 위반 여부를 판정한다. 선택 인자 `source_fn(t) → (v_src, R)`로 경로 전원과 경로저항을 시간에 따라 바꿀 수 있다(E16 충전 통합). 주지 않으면 이전 계산과 같다.

**제어기** 두 설계 모두 상태궤환 [i_p, v_s, v_bus, i_h] + 버스전압 적분 → 브리지 전류지령(±84 A 포화) → 내부 전류 법칙 → 변조율, 링크전압 PI의 같은 구조이며 788 V·5 kW에서 한 번 설계한 이득을 전 범위에 고정 적용한다. 채택 설계는 공칭 모델과 직전 지령으로 고속 상태 [i_p, v_s, i_h]를 한 주기 앞으로 예측해 연산 지연을 보상하고, 주 극점 감쇠비를 0.95로 둔다(극 {−ζω±jω√(1−ζ²), −ω, −ω/3, −2.5ω}, ω = 2π·4.8 kHz).

**Stage B 스위칭 모델 (`model_stage_b_switching.py`)** 평균모델의 6상태에서 DAB 응답(i_dab)을 누설 인덕턴스 전류 i_L로 바꾸고, H-브리지 두 레그와 DAB 두 브리지의 실제 스위칭 상태로 적분한다(중점법 5 ns). 레그 에지는 적분 간격 안의 정확한 위치로 처리해 듀티 양자화가 없고, 데드타임 동안 노드 전압은 출력용량(선형 또는 전압 의존) 충방전으로 간격마다 이어서 적분한다. DAB 두 브리지의 에지는 H-브리지 반송파의 반주기 중심에 대칭(±φ/2)으로 고정하고, 위상 변경은 전이 반주기의 위상차를 이전·새 위상의 평균으로 두어 직류 편류를 막는다(위상 부호 무관). DAB 데드타임 중 전류가 0을 지나면 0에 고정한다(영전류 클램프). DAB 링크전류는 누설 인덕턴스 −10 % 기준 앞먹임에 측정 링크전류로 추정한 전류비 보정을 더해 정하고(예측 40 A 미만의 저전류 구간은 측정 전류와의 차를 가산 보정), H-브리지 데드타임은 전류별 전이 오차 교정표의 일부(경부하 60 % → 80 A에서 100 %)만 보상한다. 센서는 기본 이상이며 채널별 양자화·잡음·이득·오프셋 오차를 넣을 수 있다. DAB 손실은 직전 주기 평균 전력에 평균모델과 같은 효율을 적용한다. 이 변조기 설계(전류비 보정, 저전류 가산 보정, 부분 보상)와 센서 요구 사양은 E12에서 정한 것이다. 선택 기능으로 링크전류 센서 고장 주입과 타당성 감시(링크 전하 수지 대조, E14)가 있다. 또 제어기용 V_bat을 플랜트와 따로 주는 `ctrl_vbat`과, 플랜트 경로 전원을 정해진 시간 동안 선형으로 바꾸는 `src_t0`·`src_t1`·`src_vbat1`이 있다(E16). 기본값에서는 이전 계산과 비트 단위로 같다.

**판정 (`stage_b_tests.py`)** Tier-1(계약 내 ±10 kW 스텝): 400±8 V, 20 ms 시점 ±4 V, ±4 V 밖이면 1 ms 내 재진입, 마지막 1 ms 리플 ≤ 0.1 V, 포트 한계, 경로·필터 전류 ≤ 90 A. Tier-2(1↔25 kW): 포트 한계, ≤ 93.75 A, 버스 384–416 V, 최종 ±4 V. 두 등급 모두 마지막 1 ms의 i_h 변동폭 ≤ 1 A, 변조율 변동폭 ≤ 0.01의 내부 진동 검사를 더한다.

참고 사항
- **E1 난수**: 공차 표본은 MATLAB의 Mersenne Twister(`rng(0)`, `rng(3)`)와 같은 난수열로 뽑으므로 Python과 MATLAB이 같은 표본을 쓴다. GNU Octave의 `rng`는 초기화 방식이 달라 공차 표본이 다르게 뽑힌다(Octave 실행 시 고정 타이밍 17/20·최대 37.3 %). 난수를 쓰지 않는 셰딩·프리차지와 8위상 공칭 사례는 Octave에서도 같은 값이 나온다.
- **E2 대조 허용오차**: 발산하는 실패 궤적(지연 15 µs 등)은 부동소수점 차이가 증폭될 수 있어 진단 조건의 지표 허용오차를 1e-3으로 완화한다. 판정은 모든 조건에서 같아야 한다.
- **E5 비교 설계**: 내부 진동 검사를 비교 설계에도 똑같이 적용했다. 공칭 지연 격자의 판정은 이 검사가 없던 판정과 같고, 추가 지연 +3.0 µs의 Tier-2 부하 감소 3건만 내부 진동으로 실패가 된다(보고서 인용 수치에는 영향 없음).
- **E9**: 지연 여유 8.0 µs는 탐색 상한이다(실제 여유는 그 이상).
- `results/` 안의 `*_matlab.json`은 이 묶음을 정리하면서 **GNU Octave 8.4**로 실행한 결과다(파일의 `matlab_version`/`tool` 항목에 실행 도구가 기록된다). 보고서의 MATLAB 수치(E1, E2)는 MATLAB R2024b 실행값이다.

## 7. 검증 범위의 한계

- Stage B는 평균모델(E2–E9, E11)과 스위칭 ODE 모델(E12)로 검증했다. 스위칭 모델에도 DAB 소자 출력용량·소자 스위칭 과도·스위칭 손실·기생 인덕턴스·자화 인덕턴스·센서 대역 제한은 포함하지 않는다(센서 양자화·잡음·이득·오프셋 오차는 E12 sensors, 링크전류 센서 고장은 E14에서 따로 다룬다). H-브리지 데드타임 보상 오차 계산은 전이 중 전류 기울기를 무시하므로 소프트 스위칭 구간에서 작은 잔여 전압오차가 남는다. 소자 수준 회로 모델과 보호 상태기계의 스위칭 모델 결합은 다음 단계다.
- 보호·기동(E14)의 정지·기동 전이는 평균모델에 운전 모드를 더한 것이며 차단 소자 동작 시간·탈포화 검출·소자 수준 과도는 포함하지 않는다. 링크 프리차지는 이상 SPS 해석이다. E12 결과는 링크전류 센서 타당성 감시 없이 계산했다(감시는 정상 센서 84건에서 동작하지 않음).
- 기준 구조 비교(E13)는 평균모델이며 세 구조가 같은 Stage A 모델(이상 2:1 + R·L)과 이상 정전력 부하를 쓴다. ③′의 바이패스 스위치·모드 전환 과도와 손실·반도체 수·정격 VA 비교는 포함하지 않는다.
- Stage A와 Stage C는 스위칭 ODE 모델이며 손실은 회로 파라미터에 따른 추정값이다. 소자 스위칭 과도, 센서 지연·오프셋, 다상 동기는 포함하지 않는다.
- Stage C는 3 kW 후보 설계의 결과이며 현재 요구전력(약 5 kW)에 대한 재설계가 남아 있다.
- 부하 승인 계층(E8)은 1 ms 축약 부하 모델이며 전기모델과 결합하지 않았다.
- Python·MATLAB 이중 구현 대조(E2)는 구현의 일관성을 보이며 모델의 물리적 정확도를 뜻하지 않는다.
- 손실·정격 비교(E15)는 데이터시트 값과 일정 비율 자성체 손실 규칙으로 계산한 설계 단계 추정이다. 열 결합(접합온도 반복 계산), 자성체 개별 설계, 기생 성분, 경부하 버스트 운전 같은 운전 최적화는 포함하지 않는다. Stage A 손실은 E1 모델(출력용량 에너지 고정)을 쓴다. 스위치 VA는 소자 전압 등급 × 정격 운전 스위치 실효전류의 합이고 비용이 아니다.
- 충전 통합(E16)은 Stage A를 정적 등가(V_bat/2 + R_A·i_ch)로 두고 충전기를 이상 전류원으로 둔다. V_A 노드 공진(회로 모델 TB07에서 주기 약 30 µs)이 없으므로, 충전전류가 100 µs보다 빠르게 바뀌는 경우의 경로전류 첨두를 작게 본다.
