# 그림 목록(장별 추천)

- 1절은 [01_최종보고서_구성안.md](01_최종보고서_구성안.md)의 장 구성에 맞춘 **추천 그림**이다. "10-26판"은 중간보고서 원고(`report/interim4`)에서 이미 쓴 그림이고, **새 그림**은 10-27·10-28 검증(E27–E29, TB21–TB23)에서 나온 것이다.
- 그림 번호는 제안이다. 캡션 초안은 근거 문서의 그림 설명을 줄인 것이다.
- 2절은 새 그림을 미리 보기로 붙였다(GitHub에서 바로 확인).
- 부록은 `tools/build_index.py`가 저장소의 그림을 모두 모은 목록이다(이 파일의 부록 위는 손으로, 부록은 자동으로 고친다).
