# 핵심 수치와 출처

- 보고서 요약·결론·장 첫머리에 쓸 수치를 장 순서로 모았다. **모든 값은 아래 출처 문서에서 그대로 옮겼다.** 보고서에 넣기 전에 "출처" 열의 문서와 "근거 파일" 열의 결과 파일을 다시 열어 대조한다.
- 출처 문서의 수치는 각 시험 당시 결과 JSON과 대조한 값이다. docs/20 6절 표가 시험별 수치의 기준이고, 각 문서가 그 상세다.
- 근거 파일 경로는 저장소 최상위 기준이다(정식 보고서 본문에는 경로를 쓰지 않는다).
- **2026-10-29 갱신.** Stage A가 A25R로 바뀌어 손실·충전·클램프 수치가 바뀌었다. 요약·결론에는 **0절(최종 설계 값)**을 쓴다. 1–7절은 각 시험 당시의 값이며, 150 kHz Stage A로 낸 값에는 "(150 kHz)"를 붙이고 최종 값을 함께 적었다. 8–11절은 10-28 이후의 시험이다. **외부 검토 대응(E38)으로 0절의 손실·클램프·충전·이중 고장 값을 다시 바꿨다(12절).**
