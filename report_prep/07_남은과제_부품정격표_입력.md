# 남은 과제와 부품 정격 표

2026-10-29 갱신, 2026-10-30 최종 검토 대응 반영. 검증 과제는 모두 끝났고, 부품 정격 표는 세 번(E34·E37·E38) 만들고 재검토로 P5를 다시 판정했다(E39). 보고서 작성 전 최종 검토(docs/45)에 대응해 전형값만 있는 손실 인자에 규칙 L을 적용해 P1·P5–P8·C\_A를 다시 판정했다(E40, docs/46). E39 클램프 선정은 불통과여서 가지 3개로 다시 골랐다. 남은 불통과는 없다. 이 문서는 최종 보고서 16장(부품 정격 표)과 19장(향후 계획)의 입력이다.

## 3. 남은 설계 과제(보고서 19장)

남은 불통과는 없다(E38–E40). 남은 일은 다음과 같다.

1. **새 인터페이스 요구의 확인.** Stage C 보호 일시 정지(4 kW/ms, ≤ 12.4 ms, 48 V 배터리 최대 66 J)는 조정형 Stage C 제어기의 입력 제한으로, 이중 고장 400 V 부하 정지(전용 배선 신호 뒤 3 ms 안에 0)는 차량 400 V 부하의 응답으로 확인해야 한다.
2. **고전압 팩(224s·240s) 충전 중 정지.** W460 설정(511/506 V)의 V\_A 수준 결과만 있다. 사건 중 Stage B가 버스를 붙잡는 동작과 회로 확인.
3. **조건부 부품 확인.** 클램프 저항 891SP의 열용량·저항값별 허용치(2.4·2.7 Ω), 제동 저항 허용치(여유 2 %, 0.1 s보다 짧은 펄스의 곡선 대조), C\_fly 후보의 다른 온도 전류 정격, 클램프 스위치(FF2MR12KM1P 데이터시트가 2020년 예비판 V2.0이라 단종·개정 여부 확인, 대체 CAB530M12BM3와 열 기준점이 다름).
4. **클램프 문턱 검출 정확도 실현.** 사양 팩 높은 쪽 +0.10 %는 엄격하다. 이를 낼 검출 회로(분압기·절연 증폭기·비교기)의 설계와 온도·노화 오차를 확인해야 한다(W460은 +1.0 %).

## 4. 후속 과제(결론을 바꾸지 않아 보고서 19장에 적을 것)

- A25R로 다시 확인하지 않은 항목: 정지 모듈 C\_fly 전압 요구, Stage B 보호·강등 시험(E17·E19–E21)의 A25R 확인
- 최종 검토 대응(docs/46 7절)에서 하지 않은 것: C\_fly 공차 범위(후보 공칭 −4 %에 J ±5 %·K ±10 %)의 공진주파수·손실 재계산, E18 가치 지도를 셰딩을 준 ⑤로 다시 계산(칸 판정이 바뀌는지 미확인), Stage A ZVS 보조 운전 변형, 대규모 몬테카를로(사용자 결정 2026-10-29)
- 클램프 오동작의 원인(문턱 오차와 V\_A 과도·잡음) 모의와 잡음이 계속되는 반복 오동작, 강제 끔 순간의 di/dt·스위치 과전압(이상 스위치 모델이라 보지 않음), 회로 진단(TB33 D33b)에서 클램프가 0.5 ms 켜진 채 남을 때 켜고 끄는 순간의 Stage A 출렁임(위상 첨두 155.2 A)과 턴오프 기준 초과 7번(최대 7.8 A)
